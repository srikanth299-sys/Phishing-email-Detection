      Privacy & how this works

      This application is a static website: three plain files (HTML, CSS, JavaScript) that run entirely in your browser.

      • Local analysis: the text you paste is processed only by the JavaScript in this page, on your own device, in memory. Nothing is transmitted anywhere.
      • No accounts, no tracking, no telemetry: there is no code that phones home, no cookies for analytics, no third-party scripts, fonts or icons.
      • You can go offline: download the folder and open index.html without an internet connection — it still works.
      • Host for free: because it is static, you can publish it free on GitHub Pages, Cloudflare Pages or Netlify Drop with no server and no database.
      • How scoring works: every warning sign has a fixed number of points (shown next to each finding). The risk score is simply those points added up, capped at 100. Nothing hidden.
      Heads up about accuracy: this tool uses simple text-pattern rules that any learner can read and improve. It may occasionally miss a clever attack or over-flag a legitimate message. It is designed to help people think before they click, not to replace a real mail-security gateway, a spam filter, or a human security team.
